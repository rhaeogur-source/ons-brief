# SPEC — 출동 전 원인 브리핑 카드

기준 문서: Claude Docs「출동 전 브리핑 앱 개발 명세서」 + 실습 README. 모호한 항목(A1–D6)은 문서 11장의 기본값으로 **확정**(2026-10-13).

## 1. 실행

```
python prepare.py                       # 기본 경로, 연락처 마스킹 ON
python prepare.py --no-mask             # 연락처 그대로
python prepare.py --now 2026-10-08T21:00
python -m unittest discover -s tests -v
```

- 의존성: Python 3.10+, `openpyxl`
- 결과: `dist/index.html`(데이터 내장, 더블클릭으로 열림) · `dist/briefing.json` · `dist/cards/NN_<기지국ID>.md`(출동 대상만)

## 2. 구조

```
06_출동전브리핑/
├── prepare.py            읽기 → 판정 → 원인 추정 → 점수 → 출력
├── templates/index.html  화면 템플릿 (/*__BRIEFING__*/ 자리에 JSON 주입)
├── config/
│   ├── config.json       점수 가중치, 노후 기준, 안전 문구
│   ├── alarm_map.csv     알람명 39종 → 표준유형 13종
│   ├── causes.json       실제원인 20종 → 원격/현장 구분 + 자재
│   └── checklist.json    표준유형 → 자재 (원인이 없을 때 사용)
├── tests/test_prepare.py
└── dist/                 생성물
```

입력 기본 경로: `../alarm_log_20261008.csv`, `../site_master.xlsx`, `./장비이력.xlsx`, `./조치이력.xlsx` (README의 `../03_…`, `../00_common/` 경로는 없음 → B3).

## 3. 적용한 규칙

| 항목 | 규칙 |
|---|---|
| 미해제 (B1) | `상태=='미해제'` 또는 `해제시각` 빈값 → 31건. 그중 `상태=='해제'`인 15건은 `확인필요` |
| 날짜 (B2) | 6가지 형식 파싱, MM/DD 가정. 실패하면 `meta.warnings`에 기록 |
| 기준시각 (C4) | 로그의 발생·해제시각 중 최댓값 (2026-10-09 03:36). `--now`로 덮어씀 |
| 카드 대상 (A2) | 기본은 미해제 31곳. 화면의 "해제된 기지국 포함"을 켜면 225곳 |
| 유력 원인 (C1) | ① 같은 기지국·같은 증상의 최빈 원인 = **근거** ② 없으면 전 기지국 같은 증상의 최빈 원인 = **추정** ③ 둘 다 없으면 추정하지 않음 |
| 근거 (C2) | `조치이력.xlsx` 행 번호·조치일·기지국 최대 5건, 재발 표시 |
| 자연복구 (B7) | `원인 미상(자연복구)`는 원인 후보에서 제외하고 횟수만 표시 |
| 점수 (C5) | 등급(50/35/20/5) + 경과(시간당 2, 최대 20) + 반복((당일건수−2)×3, 최대 15) + 다중(5) + 5G(10), 최대 100. 70↑ 긴급, 40↑ 우선 |
| 분류 (C7) | 원인이 모두 원격형 → 원격 조치 먼저 / Critical·Major → 지금 바로 출동 / 그 외 → 다음 정기점검 |
| 자재 (C8) | 원인별 자재 우선, 없으면 표준유형별 자재. 고소작업이면 안전대·헬멧·로프 추가 |
| 장비 (B6) | 알람 장비구분과 같은 장비를 누적고장 많은 순으로 나열. 설치일 또는 교체일로부터 8년 이상이면 노후 |
| 펌웨어 비교 (A4) | 같은 구분·모델·펌웨어 3대 이상이고 평균 고장이 구분 평균의 2배 이상이면 `펌웨어의심`. 해당 기지국들의 조치이력 원인 중 50% 이상을 차지하는 원인이 있으면 공통 원인으로 표시 |
| 연식 비교 (A4) | 구분 × 설치연도(~2016 / 2017~2020 / 2021~)별 평균 고장 |
| 지도 (F5) | Leaflet 1.9.4 (cdnjs) + OpenStreetMap. 오프라인이면 목록만 표시 |
| 개인정보 (D4) | 연락처 마스킹이 기본 (`010-****-1234`). 체크 상태만 localStorage에 저장 |
